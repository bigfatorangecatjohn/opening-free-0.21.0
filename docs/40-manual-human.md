# 开机动画 Free — 说明书（给人）

一个给 DeepSeek Harness 桌面版用的开机动画插件：每次打开/刷新页面，17.99 秒的全屏序列铺满界面，播完自动消失，点一下或按任意键立刻跳过。

- 包名：`dsh-opening-free`　版本：`0.1.0`
- 形态：DSH 客户端插件（bundle），挂在 `shell.overlay` 整帧浮层上
- 体积：`client.js` 约 815 KiB（四种语言 × 完整/简短 共八条音轨 + 鲸鱼图全部内联，无外部请求）

---

## 一、它长什么样

白纸底、深墨字、DeepSeek 蓝的表盘。开机时按顺序走完五步访问协议，然后收尾：

| 步骤 | 中文 | English | Русский | 日本語 |
|---|---|---|---|---|
| 1 | 需要访问许可 | Access Permission Required | Требуется Разрешение На Доступ | アクセス許可が必要です |
| 2 | 身份资料确认 | Identity Verification | Подтверждение Личности | ご身分の確認 |
| 3 | 接收访问需求 | Access Request Received | Запрос На Доступ Принят | アクセス要求を承りました |
| 4 | 开始读取权限 | Permission Read Started | Начато Чтение Прав | 権限の読み取りを開始 |
| 5 | 读取完毕，核验通过 | Read Complete · Verified | Чтение Завершено. Проверка Пройдена | 読み取り完了 · 確認済み |
| 收尾 | 欢迎回来，指挥员 | WELCOME BACK, COMMANDER | ДОБРО ПОЖАЛОВАТЬ, ТОВАРИЩ | おかえりなさいませ、ご主人様 |

画面元素：粒子场（离子化，浮现又消失）、缺口双环反向旋转、开场浮现再淡出的鲸鱼 logo、左上协议标签、顶栏 hex 计数器、左下逐条打勾的操作日志、底部 1px 进度条与游标。

音频：开场四声水滴叮咚（A6/E6 来回），之后每一步一句人声，收尾三行诗式的祝词；底下垫一层很轻的 Am–F–C–G 电子垫乐，人声出现时自动压低。

**八种模式**，各自一条独立音轨，只有被选中的那一条会播放：

| 模式 | 内容 | 时长 |
|---|---|---|
| 中文 / English / Русский / 日本語 | 五步访问协议 + 收尾 | 各 18.00 秒（锁死） |
| 中文（简）/ English (Short) / Русский (Кратко) / 日本語（簡） | 只留开场四声水滴叮咚 + 收尾那一句（鲸鱼照常浮现再淡出） | 3.7 / 3.8 / 4.3 / 4.4 秒 |

短版的开场音频与完整版**逐样本相同**（同一条 chime 被截取），差别只是省掉了五步和中间垫乐；适合不愿意看长片的人。默认是完整版中文。

## 二、怎么装（三步）

1. 打开 DSH 桌面版 →「设置」→「插件」
2. 点「安装本地插件（bundle）」，选中 `dsh-opening-free-0.1.0` 这个文件夹（不是 zip）
3. 等进度条走完（约 1–2 分钟，pnpm 在装链接）→ 提示 `applied` 后**刷新页面**（Ctrl+R）

刷新后应当立刻看到开机序列。详细排错见 `INSTALL.md`。

## 三、怎么切语言

「设置 → 开机动画」——这是插件自己的设置页，四张卡片：中文 / English / Русский / 日本語。选一张，**刷新页面**生效（下次开机就是那个语言）。

选中的语言存在浏览器 localStorage 的 `dsh-opening:lang` 里；没选过默认中文。

## 四、怎么停用 / 卸载

- 只想这次不看：在序列播的 18 秒里点一下鼠标或按任意键，立即跳过并淡出。
- 系统开了「减少动态效果」（`prefers-reduced-motion`）：序列直接不播。
- 想彻底关掉：设置 → 插件 → 找到 `dsh-opening-free` → 停用（或卸载）。

## 五、已知限制（品评时请当作已知项）

1. **只有开机/刷新才播**，不是每次切页面都播。
2. **自动播放策略**：个别环境下浏览器会拦截 `audio.play()`，此时动画照常走完但没有声音——再点一次或刷新通常就有。
3. **体积换音质**：为控制分发体积，音轨用 Ogg Vorbis q0.5（约 85 KiB/条）。如果愿意接受 4.7 MB 的包，可以换回未压缩 WAV。
4. **日语音色**是成人女声抬音高（×1.14 + 1.12 倍速）模拟的「轻快小女孩」，不是真正的儿童音色——Kokoro 模型没有儿童声线。
5. **鲸鱼 logo 是 DeepSeek 官方的**，这里作为同人致敬使用；本插件与深度求索官方无关，不要商用。
