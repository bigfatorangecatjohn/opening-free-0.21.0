# 安装（三步 + 排错）

## 三步

1. 打开 DSH 桌面版 → 左下「设置」→「插件」
2. 点「安装本地插件（bundle）」，选择本文件夹 **`dsh-opening-free-0.1.0`**（是整个文件夹，不是压缩包）
3. 等 1–2 分钟，直到出现 `applied`，然后按 **Ctrl+R** 刷新页面

刷新后应立刻看到白底、蓝色表盘的开机序列，播约 18 秒后自动消失。

> 想跳过：序列播放时点一下鼠标或按任意键即可立刻结束。

## 切语言

「设置 → 开机动画」→ 四张卡片选一张（中文 / English / Русский / 日本語）→ 刷新页面。

## 排错

| 现象 | 处理 |
|---|---|
| 安装卡住 2 分钟以上 | 第一次装要走 pnpm 解析，慢是正常的；超过 5 分钟再看日志 `~/.dsh/profiles/<profile>/.plugin-manager/logs/` |
| 装了但没画面 | 先 Ctrl+R。仍然没有就去「设置 → 插件」确认 `dsh-opening-free` 是启用态 |
| 有画面但没声音 | 浏览器自动播放策略拦了音频；点一下页面再刷新，或调大系统音量 |
| 动画一闪而过 | 你在播放期间点了鼠标/按了键（这是跳过功能） |
| 想换回原样 | 设置 → 插件 → `dsh-opening-free` → 停用 |

## 卸载

设置 → 插件 → `dsh-opening-free` → 卸载。卸载后刷新页面即恢复原样，不留残留文件。
