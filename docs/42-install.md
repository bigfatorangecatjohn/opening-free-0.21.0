# 安装 · 三步（+ 排错）

这个包是 DSH **本地插件（bundle）**，安装只需要在 DSH 界面里选一次文件夹。zip 从 [GitHub Releases](https://github.com/bigfatorangecatjohn/opening-free-0.21.0/releases/latest) 下载——仓库里不放 zip（`dist/` 是本地生成物）。

## 三步

1. 打开 DSH 桌面版 → 左下角「设置」→「插件」。
2. 点「安装本地插件（bundle）」，选中 `dsh-opening-free-0.21.1` 这个**文件夹**（是整个文件夹，不是 zip）。
3. 等它显示 `applied`，回到页面按 **Ctrl+R** 刷新。

刷新后应立刻看到开机序列：一道蓝色数据流扫过，鲸鱼从光点里游出来，全息圆环旋转呼吸，最后浮出「欢迎回来，指挥员」，底部一条蓝色呼吸灯竖线走到 100%。

> 压缩包里的 `安装.cmd` 会把插件文件夹路径复制到剪贴板；第 2 步在文件选择窗口里按 Ctrl+V 粘贴即可。它只做复制路径和打印说明，不改动任何文件。

## 换语言 / 试听

「设置 → 开机动画」：

- 八张卡片（四语完整版 + 四语简版）。选中后**下次刷新页面**生效。
- Preview 六个按钮：四语完整连播（约 72 s）、四语简版连播（约 16 s）、四条简版单条。预览不写设置，点一下或按任意键跳下一版。

## 排错

| 现象 | 处理 |
|---|---|
| 安装卡住 2 分钟以上 | 第一次装要走 pnpm 解析，慢是正常的；超过 5 分钟看 `~/.dsh/profiles/<profile>/.plugin-manager/logs/` |
| 装了但没画面 | 先 Ctrl+R。仍然没有就去「设置 → 插件」确认 `dsh-opening-free` 是启用态 |
| 有画面但没声音 | 浏览器自动播放策略拦了音频；点一下页面再刷新，或调大系统音量 |
| 动画一闪而过 | 播放期间点了鼠标/按了键（这是跳过功能） |
| 只有声音没有画面 | 换一个显卡驱动/缩放比试试；仍不行请把 `client.js` 与浏览器版本一起报给维护者 |
| 想换回原样 | 设置 → 插件 → `dsh-opening-free` → 停用 |

## 卸载

设置 → 插件 → `dsh-opening-free` → 卸载。卸载后刷新页面即恢复原样，不留残留文件；浏览器 localStorage 里的 `dsh-opening:lang` 会留着，重装后沿用。

## 系统要求

- DSH 桌面版（宿主版本需支持 bundle 与 `shell.overlay`）
- 任意现代浏览器内核（DSH 自带）
- 音轨为内联 Ogg Vorbis，无需额外解码器
